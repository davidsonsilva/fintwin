# 👁️ Ver Plano Atual

Leia a memória de planejamento mais recente (com prefixo `planning/`)
e apresente um resumo ao usuário:

1. Status (EM DISCUSSÃO / PLANEJADO / EM EXECUÇÃO / CONCLUÍDO)
2. Resumo do objetivo
3. Progresso atual (se em execução)
4. Principais decisões
5. Correções registradas (se houver)

Se não houver plano ativo, informe ao usuário e sugira usar `/discutir-tarefa` para começar um novo planejamento.
